## 一、系统精简：技能升星 + 装备系统重构

### 1.1 为什么冗杂？

| 系统 | 当前问题 | 精简思路 |
|------|----------|----------|
| **技能升星** | 1→5星，每星+12%伤害，感知弱 | 改为**1→3星质变**，每星改变技能形态 |
| **装备5格** | 武器+头胸手鞋，词缀随机但效果平淡 | 合并为**2格：武器+护甲**，效果显性化 |
| **装备词缀** | 锐利/迅捷/汲取等，数值微调 | **移除词缀系统**，效果并入遗物池 |

### 1.2 精简后架构

```
构筑层（局内）：
  ├─ 技能槽：4格，每技能可升3星（质变）
  ├─ 装备槽：2格（武器+护甲），决定基础战斗风格
  ├─ 遗物槽：软上限16，核心构筑深度
  └─ 指挥官指令：3-5格，战斗交互层
```

**技能升星质变示例**：

| 技能 | 1星（基础） | 2星（扩展） | 3星（质变） |
|------|------------|------------|------------|
| 火球 | 单体火伤 | 命中后爆炸（小AOE） | 爆炸后留下火池（持续DOT） |
| 盾击 | 单体伤害+眩晕 | 伤害+眩晕+破甲 | 伤害+眩晕+破甲+击退 |
| 后撤射击 | 单体伤害+后跳 | 伤害+后跳+穿透 | 伤害+后跳+穿透+弹射 |

**装备2格化**：

| 槽位 | 作用 | 示例 |
|------|------|------|
| **武器** | 决定普攻类型、攻击范围、基础攻速 | 双手剑（慢/高伤/顺劈）、长弓（远/穿透）、双匕（快/连击）、法杖（中/弹射） |
| **护甲** | 提供防御+1个战斗被动 | 重甲（高防+受击反伤）、皮甲（中防+闪避）、布甲（低防+技能CD-20%） |

特定角色相邻站位触发羁绊。

| 羁绊 | 条件 | 效果 |
|------|------|------|
| **钢铁前线** | 战士+战士相邻 | 互相分担40%伤害 |
| **元素共鸣** | 法师+法师相邻 | 技能有30%几率触发另一名法师的技能 |
| **影舞** | 刺客+刺客相邻 | 闪避后另一名刺客也获得闪避 |
| **箭雨** | 弓箭手+弓箭手相邻 | 普攻有20%几率触发另一名弓箭手的普攻 |
| **光暗平衡** | 法师+刺客相邻 | 法师技能伤害+20%，刺客暴击+15% |
| **战猎协同** | 战士+弓箭手相邻 | 战士嘲讽时，弓箭手对其目标伤害+50% |

#### 系统C：突变节点（Mutated Nodes）

极低概率（5%）出现的**变异节点**，规则完全改变。

| 突变类型 | 效果 |
|----------|------|
| **反转战斗** | 你控制敌人，AI控制你的队伍 |
| **1v1决斗** | 只上阵1人，敌人也只有1个（属性x4） |
| **生存模式** | 无限波次敌人，坚持越久奖励越好 |
| **镜像对决** | 敌人是你的完全镜像（装备/技能/遗物） |
| **元素限定** | 只有特定元素伤害有效 |
| **无装备战** | 临时卸下所有装备，纯靠技能和遗物 |
