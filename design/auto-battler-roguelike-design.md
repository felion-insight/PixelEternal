# Pixel Eternal → 轻操作自走棋 Roguelike 设计思路

**文档版本**：v1.0  
**状态**：现行主设计（替代旧 ARPG 爬塔主循环）  
**相关旧文档**：[`growth-and-gameplay.md`](./growth-and-gameplay.md)、[`dungeon-and-progression.md`](./dungeon-and-progression.md) 部分内容已过时，仅作参考。

---

## 1. 定位转变

| 维度 | 现状（旧） | 目标 |
|------|------------|------|
| 操作 | 单角色 WASD + 技能实时操作 | 开战前布阵；战斗中算法自动移动/攻击 |
| 单位 | 1 名玩家角色 | 固定 4 名可养成角色编队 |
| 恶魔塔 | 持久角色爬 240 层 + 弱 Run 层 | 完整单局 Roguelike：每局地图/节点不同 |
| 装备/技能 | 永久穿戴 + 完整技能栏 | 开局统一「普攻 + 1 主动」；技能/装备/遗物均局内获取，结算清空 |
| 养成 | 塔内打经验直接升级 | 战斗产经验 → 局外手动分配 → 升级/转职 |

一句话：**局外养人（等级/职业模板），局内养局（站位 + 技能槽填充 + 装备 + 遗物），战斗交给算法。**

---

## 2. 核心循环

```
主城编队养成 → 进入恶魔塔开局 → 选节点推进
  → [战斗] 布阵 → 自动战斗 → 经验与局内奖励 → 继续选节点
  → [事件/商店/恢复] 决策后继续
  → 最终 Boss 或失败 → 结算 → 主城分配经验/升级/转职
```

- **局外**：四人等级/职业树、解锁内容、外观等。
- **局内**：棋盘站位、技能槽（≤4 主动）、装备、遗物、金币与商店；全部不写回永久栏位。

---

## 3. 四人编队

初始四人对应四基础职业：战士 / 射手 / 法师 / 刺客（见 `config/class-config.json`）。一转/二转仍为局外转职目标。

| 职责 | 基础职业 | 布阵倾向 |
|------|----------|----------|
| 前排承伤 | 战士 | 靠近敌方 |
| 后排持续输出 | 射手 | 远离敌方 |
| 范围/控场 | 法师 | 中后排 |
| 切后/突进 | 刺客 | 侧翼或对位后排 |

### 3.1 开局负载（全职业统一）

- **普通攻击**：不占技能槽；自动战斗保底行为
- **1 个职业主动技能**：占用技能槽第 1 格；由当前转职决定

开局技能栏：`[主动] [空] [空] [空]` + 始终可用的普攻。

| 规则 | 说明 |
|------|------|
| 上限 | 最多 4 个主动技能（普攻额外） |
| 开局占用 | 1 槽已用，剩 3 空槽 |
| 填充 | 局内掉落 → 手动装配 |
| 满槽 | 替换或分解 |
| 自动释放 | 槽位优先级 + CD；普攻 fallback |

### 3.2 单局构筑丰度目标

基准：约 **14 层**节点图；中层首领约在第 7 层（layer 6）、终末魔王在第 14 层（layer 13）；全程约 1 中层 Boss + 1 Final，不再「每三层一 Boss」。

**技能**

| 阶段 | 单角色目标 |
|------|------------|
| 开局 | 1/4 |
| 前期（至第 1 Boss） | 多数 2/4 |
| 中期 | 主力 3/4，其余 2–3/4 |
| 终局前 | 全员 3–4/4；1–2 名核心满 4 |

- 单局技能获取约 **10–14 张**
- 不默认全员满 4；倾斜资源合法

**装备**：每角色 **1 武器 + 4 防具（头/胸/手/鞋）**，无饰品

| 阶段 | 目标 |
|------|------|
| 前期 | 武器 0–1；防具 0–1 |
| 中期 | 主力武器 + 2 防具 |
| 终局 | 多数武器 + 2～3 防具；核心可接近满 5 |

- 单局装备约 **12–16 件**（武器 4–6，防具 8–12）
- 饰品向效果走遗物

**遗物**

| 阶段 | 数量约 |
|------|--------|
| 第 1 Boss 后 | 1–2 |
| 第 2 Boss 后 | 3–5 |
| Final 前 | 5–8（软上限 10） |

## 4. 棋盘与轻操作

- **横向战场**：左己右敌；`boardRow` 为前后深度（0 前排靠近中线），`boardCol` 为上下车道
- 己方建议 **4 车道 × 3 深度**；开战前点选备战席再点己方格布阵
- 战斗中纯自动：寻敌、走位、普攻、技能、死亡退场
- 目标选择默认最近敌人；可按职业偏向

---

## 5. 恶魔塔 Roguelike 单局

每局独立 `runSeed`，节点类型：战斗 / 精英 / 事件 / 恢复 / 商店 / Boss。

- **呈现**：选路 / 商店 / 事件 / 休整 / 战利品为独立全屏场景（Canvas 场景底 + HUD），不是棋盘上的浮窗
- 精英主产遗物三选一
- 常规战斗：金币 + 技能或装备
- Boss：高稀有技能/装备；视节奏给遗物（中层 1 + 终局 1）
- 结算清空局内全部构筑；带出未分配经验池
- 无「死亡回退 5 层」；下一局从起点重开

---

## 6. 局外成长

```
战斗 → RunExp → AccountExpBank → 主城手动点到四人 → 升级 → 转职
```

- Meta：等级、经验银行、职业/转职、卡池解锁、通关记录
- Run：站位、技能槽、装备、遗物、局内金币

转职改变：成长模板 + 开局起始主动 + 本职掉落权重。

---

## 7. 局内构筑三件套

1. **技能**：角色绑定，≤4 主动  
2. **装备**：角色绑定，1 武器 + 4 防具  
3. **遗物**：队伍共享被动（由精英加护演化）
