## 1. 一句话定位

**Pixel Eternal（像素永恒）** 是一款基于 HTML5 Canvas 的像素风游戏。  
当前默认主循环是：**四人编队 · 开战前布阵 · 战斗自动进行** 的自走棋 Roguelike（恶魔塔）；仓库中仍保留完整的单人 ARPG 爬塔 / 秘境 / 铁匠等系统，在自走棋关闭时可回退。

设计核心：

- **局外几乎不养成**（每次从 Lv.1 开荒）
- **局内养局**（站位、技能、装备、遗物、休息处加点）
- **战斗交给算法**（玩家只在开战前布阵与选路线）

## 2. 技术与工程结构

| 项 | 内容 |
|---|---|
| 技术栈 | HTML5 + CSS + 原生 JavaScript，Canvas 2D |
| 存储 | LocalStorage（支持导出/导入，LZ-String 压缩） |

| 部署 | `deployment/`（由同步脚本从源码拷贝） |

## 3. 现行主循环：恶魔塔（自走棋）

### 3.1 如何开始

1. 进入主城（自走棋模式下建筑极简）
2. 与 **「开始攀塔」** 交互
3. 直接开一局 `startRun`（无独立编队大厅）

主城顶栏提示：**等级在休息处分配**。

### 3.2 一局流程

```text
开局（四人满血 Lv.1，仅起始技能）
  → 动态生成当前可选节点（通常三选一）
  → 选择节点
      ├─ 战斗 / 精英 / Boss：布阵 → 自动战斗 → 奖励
      ├─ 商店：花费局内金币购买
      ├─ 事件：叙事选项（风险/收益）
      └─ 休息：分配等级 / 回血（可复活）/ 升星 / 离开
  → 生成下一层选项 → 循环
  → 通关最终 Boss 或全队战败 / 放弃 → 结算 → 回城
```

关键规则：

| 规则 | 说明 |
|---|---|
| 地图形态 | **不预生成整图**；每走完一步再按章节节拍动态生成下一批选项 |
| 选项数量 | 默认每步 **3 选 1**；Boss / 强制休息 / 强制商店可为单选项 |
| 结算清空 | 局内技能、装备、遗物、等级均不带出塔外 |
| Meta 记录 | 通关次数、最高推进节点等；**无经验银行** |

### 3.3 章节结构（约 53 步）

| 章节 | 名称 | Boss 前步数 | Boss 层（0 起） | Boss 类型 | 节奏要点 |
|---|---|---:|---:|---|---|
| 1 | 入门层 | 15 | 15 | Boss | 前 11 步禁精英；强制休息/商店较多；精英上限 1 |
| 2 | 炼狱层 | 14 | 30 | Boss | 精英上限 3；休息/商店配额 |
| 3 | 深渊层 | 14 | 45 | Boss | 同上 |
| 4 | 终末层 | 6 | 52 | 最终 Boss | 高压收束 |

合计一局约 **53** 次节点推进，目标是给构筑足够成型时间。

### 3.4 节点类型

| 类型 | 中文 | 玩法要点 |
|---|---|---|
| battle | 战斗 | 常规战斗；金币 + 技能/装备向奖励；入门章胜利可小幅回血（不复活） |
| elite | 精英 | 更高收益；主要产出 **遗物三选一** |
| rest | 恢复 / 休整 | 分配等级点、回血（**可复活阵亡者**）、随机技能升星、离开 |
| shop | 商店 | 用局内金币买装备/遗物 |
| event | 事件 | 选项事件（治疗、金币、风险等） |
| boss | Boss | 章末 Boss；高价值技能等奖励 |
| boss_final | 最终 Boss | 通关战 |

生成约束（摘要）：

- 章节内精英数量有上限；入门前期禁止精英
- 避免「三选全是精英」
- 连续多场战斗后倾向给出休息/事件类补给选项
- 指定步数强制休息或商店，保证节奏

### 3.5 布阵与自动战斗

- 棋盘：**4 列 × 3 行**，横向布局（左己方、右敌方）
- **row 0 = 前排**，**row 2 = 后排**
- 开战前拖拽站位；开战后自动寻敌、普攻、放技能
- 战斗最长约 **90 秒**；超时按双方剩余生命判定

职业默认站位：

| 职业 | 默认位置 | 起始主动技能 |
|---|---|---|
| 战士 | 前排 | 盾击 |
| 刺客 | **中排** | 暗影穿刺 |
| 弓箭手 | 后排 | 后撤射击 |
| 法师 | 后排 | 火球 |

战斗相关规则：

- **阵亡（hp ≤ 0）后不能再参加下一场**；布阵预览中灰显
- 入门章普通战小胜回血 **不会** 复活死人
- **休息处回血可以复活** 阵亡角色
- 刺客索敌在接敌圈内偏后排，避免永远贴脸硬撞前排

### 3.6 局内养成

| 资源 | 来源 | 用途 |
|---|---|---|
| 金币 | 战斗/事件/奖励 | 商店购买 |
| 等级点 | 战斗经验转化（约 180 经验 = 1 点） | **仅休息处**手动加到角色（每角色局内等级上限 +8） |
| 技能 | 战斗奖励、Boss 奖励等 | 最多 4 个主动槽；可升星/进化 |
| 装备 | 战斗奖励、商店 | 武器/头/胸/手/鞋等局内槽位 |
| 遗物 | 精英/Boss/商店/事件 | 队伍被动；软上限约 16 |

顶部 HUD 显示：

- **金币**、**等级**（可分配点数）、**队伍**（存活人数与总血量百分比）
- **遗物图标条**（悬停可看名称与描述）

### 3.7 胜利与失败

- 任一战斗全灭 → 本局失败 → 结算 → 回城
- 击败最终 Boss → 通关 → 结算 → 回城
- 可主动「放弃」本局
- 局外角色再次开局仍是 **全体 Lv.1、无转职、空构筑**

## 4. 四人职业概要

| 职业 | 定位 | 战斗倾向 |
|---|---|---|
| 战士 | 前排承伤 / 控制与破甲向技能 | 偏坦克，站前排 |
| 弓箭手 | 远程物理 / 风筝与标记 | 后排输出 |
| 法师 | 远程法术 / 范围与控制 | 后排爆发 |
| 刺客 | 近战刺客 / 斩杀与位移特效 | 中排切入，索敌偏后排 |

技能池、遗物、敌人编成见：

- `config/auto-battler-config.json`
- `config/auto-battler-encounters.json`

数值平衡可用：

```bash
node tools/test_auto_battler_balance.js
node tools/test_tower_run_map.js
```

## 5. 主城（自走棋模式 vs 完整模式）

### 5.1 自走棋开启时（现行默认）

主城只保留：

- **开始攀塔**（唯一核心入口）

编队大厅已从自走棋主城移除；旧 `party_hall` 交互也会直接进塔。

### 5.2 自走棋关闭时（完整 ARPG 主城）

仍保留多建筑生态（代码与资源在库中）：

| 建筑 | 功能摘要 |
|---|---|
| 恶魔塔入口 | 进入旧版实时战斗爬塔（非自走棋） |
| 铁匠铺 | 强化 / 精炼 / 打造 |
| 商店 | 装备与消耗品 |
| 训练场 | 假人与测试战斗 |
| 材料秘境 | 消耗许可证打 Boss 刷材料 |
| 技能训练师 / 附魔师 / 珠宝匠等 | NPC 服务 |
| 转职官 | 职业进阶 |
| 编队大厅 | 四人编队相关入口（旧流程） |
| 编年史 / 觉醒之门等 | 叙事与成长相关 |

## 9. 近期关键设计决策（实现已落地）

1. **取消编队大厅入口**：自走棋主城只留「开始攀塔」。
2. **动态楼层 + 三选一**：不再提前展示完整地图。
3. **大幅加长章节**：入门约 15 步到首 Boss，整局约 53 步。
4. **取消经验银行**：等级只在塔内休息处分配；局外固定从 Lv.1 开荒。
5. **阵亡不上阵**：修复 0 血「假活无敌」；休息才可复活。
6. **刺客默认中排** + 偏后排索敌。
7. **顶部信息栏**：金币 / 等级 / 队伍血量文字块 + 遗物图标条。
8. **节点场景全屏化**：选路、商店、事件、休整、战利品为独立场景视图。

## 12. 给玩家的最短上手指南

1. 用本地服务器打开游戏，进入主城。  
2. 交互 **开始攀塔**。  
3. 每层从 2～3 个节点里选择路线（战斗 / 休息 / 商店 / 事件 / 精英）。  
4. 战斗前调整四人站位，开战看自动战斗。  
5. 有人阵亡后，尽快去 **休息** 复活与分配等级点。  
6. 用技能、装备、遗物堆构筑，打过四章 Boss 通关。  
7. 失败或通关后构筑清空，再开一局重新从零养局。
