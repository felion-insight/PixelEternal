## 诊断：为什么玩家构筑缺乏肉鸽感

### 当前构筑的"伪选择"

| 系统 | 表面选择 | 实际体验 |
|------|----------|----------|
| **技能** | 4角色×4技能=16种 | 但升级只是"伤害+12%"，没有玩法变化 |
| **装备** | 5件×词缀随机 | 词缀是数值微调，穿啥区别不大 |
| **遗物** | 16个上限，53层选16次 | 但大多数是"攻击+8%""防御+5%"，缺乏**机制改变** |
| **职业** | 4固定职业 | 每局一样，没有职业变异或混合 |
| **等级** | 自由分配 | 但最优解很快固定（战士全攻，法师全智） |

**核心问题**：构筑是**"数值堆叠"**，不是**"机制重组"**。每次Run的战士都是"堆攻击+吸血"，没有"这次我玩反伤流战士"或"控制流法师"的区分度。

## 解决方案：构筑肉鸽化六维改造

### 维度1：技能改造系统（Skill Mutation）—— 每次Run技能不同

**核心**：技能不是固定模板，而是**"基础效果 + 随机改造"**。

#### 技能改造表（每次获得技能时随机roll 0-2个改造）

| 改造 | 效果 | 玩法改变 |
|------|------|----------|
| **分裂** | 技能目标+1（但伤害-30%） | 单体变AOE |
| **超载** | 伤害+50%，但消耗10%生命 | 血换输出 |
| **回响** | 释放后1秒再次释放（50%效果） | 双发 |
| **吸血** | 造成伤害的20%转化为生命 | 续航 |
| **冰冻** | 附加减速30% | 控制 |
| **燃烧** | 附加DOT（每秒5%，3秒） | 持续 |
| **感电** | 命中后闪电链弹射1次 | 连锁 |
| **破甲** | 降低目标20%防御（可叠加） | 削防 |
| **吸血转化** | 不造成伤害，改为等量治疗 | 纯辅助 |
| **暴击** | 暴击率+25%，但基础伤害-20% | 赌狗 |
| **延时** | 伤害+80%，但1.5秒后生效 | 预判 |
| **反伤** | 技能释放时，若被攻击反弹50% | 防御反击 |

**示例**：你获得了一个"火球"技能，roll到了**分裂+燃烧**：
- 原来是：单体100%法强伤害
- 现在是：2个目标各70%法强伤害 + 燃烧DOT

**这局的火球和上一局的火球完全不同。**

#### 实现方式

```javascript
// 技能不再固定，而是"基础模板 + 改造"
const SKILL_MUTATIONS = {
  'split': { name: '分裂', targetMod: '+1', damageMult: 0.7 },
  'overload': { name: '超载', damageMult: 1.5, selfDamagePct: 0.1 },
  'echo': { name: '回响', echoDelay: 1000, echoDamageMult: 0.5 },
  'life_steal': { name: '吸血', lifestealPct: 0.2 },
  'freeze': { name: '冰冻', slowPct: 0.3, slowDuration: 2000 },
  'burn': { name: '燃烧', dotPct: 0.05, dotDuration: 3000 },
  'chain': { name: '感电', chainBounces: 1, chainDecay: 0.5 },
  'shred': { name: '破甲', defenseReduce: 0.2, stackable: true },
  'heal_convert': { name: '转化', convertToHeal: true },
  'crit_gamble': { name: '暴击', critBonus: 0.25, damageMult: 0.8 },
  'delayed': { name: '延时', damageMult: 1.8, delayMs: 1500 },
  'thorn': { name: '反伤', reflectPct: 0.5, reflectDuration: 500 }
};

// 获得技能时
function generateSkill(baseSkillId, heroLevel) {
  const base = SKILL_TEMPLATES[baseSkillId];
  const mutationCount = Math.min(2, Math.floor(rng() * (1 + heroLevel * 0.1)));
  const mutations = shuffle(Object.keys(SKILL_MUTATIONS)).slice(0, mutationCount);
  
  return {
    ...base,
    mutations,
    displayName: mutations.length > 0 
      ? `${base.name}·${mutations.map(m => SKILL_MUTATIONS[m].name).join('·')}`
      : base.name
  };
}
```

### 维度3：职业变异系统（Class Variants）—— 每局职业不同

**核心**：4个基础职业，但每局随机出现**2-3个变异方向**。

#### 职业变异表

| 基础职业 | 变异A | 变异B | 变异C |
|----------|-------|-------|-------|
| **战士** | 狂战士（攻击+30%，防御-20%） | 守护者（防御+40%，嘲讽范围+50%） | 武器大师（可装备任意武器，无职业限制） |
| **法师** | 元素使（元素伤害+50%，非元素-30%） | 奥术师（技能CD-30%，法力无限） | 咒术师（Debuff效果+50%，持续时间+100%） |
| **刺客** | 影舞者（闪避后隐身1秒） | 毒师（所有攻击附带中毒，但直接伤害-20%） | 背刺者（背后攻击伤害x3，正面伤害-50%） |
| **弓箭手** | 狙击手（射程+50%，攻速-30%） | 游侠（移动时攻击不减速） | 炮手（攻击有30%几率爆炸AOE） |

**实现**：开局选择角色时，每个职业随机roll 2个变异选项，玩家选1个。

### 维度4：构筑锁定与路径承诺（Build Commitment）

**核心**：早期选择**不可逆地改变后续选项池**。

#### 路径承诺系统

```
第5层（第一个重大选择）：
  ├─ 选择"火焰之心"（火伤+20%）
  │    └─ 后续商店/掉落：火系遗物出现率+50%，冰系-50%
  │    └─ 技能改造：更容易roll到"燃烧"改造
  │    └─ 最终：走向"火系大灾变"路线
  │
  ├─ 选择"冰霜之核"（冰伤+20%）
  │    └─ 后续商店/掉落：冰系遗物出现率+50%，火系-50%
  │    └─ 最终：走向"绝对零度"路线
  │
  └─ 选择"混沌之种"（随机元素+30%，但无法预测）
       └─ 后续：完全随机，但每系都有机会

第15层（第二个重大选择）：
  ├─ 选择"血之渴望"（吸血+15%）
  │    └─ 后续：生命相关遗物+50%
  │    └─ 最终：走向"不死血魔"路线
  │
  └─ 选择" glass之愿"（攻击+40%，生命-30%）
       └─ 后续：高风险高回报遗物+50%
       └─ 最终：走向"玻璃大炮"路线
```

**肉鸽感**：第5层的选择决定了你这局能玩什么，不是"看到什么强就拿什么"，而是"我承诺了火系，就要走到底"。

### 维度5：负面构筑（Negative Build）—— 像Isaac一样，负面也能玩

**核心**：某些"负面"遗物组合起来反而产生独特强力构筑。

| 负面遗物A | 负面遗物B | 组合效果 |
|-----------|-----------|----------|
| **生命上限-50%** | **防御-50%** | **"濒死狂怒"**：生命低于30%时攻击+200% |
| **无法吸血** | **无法暴击** | **"稳定输出"**：所有伤害变为真实伤害（无视防御） |
| **攻速-50%** | **移速-50%** | **"重炮"**：每次攻击伤害x3，且附带击退 |
| **金币获取-100%** | **商店价格+100%** | **"苦行僧"**：每过1层攻击+5%（无上限） |
| **技能CD+100%** | **普攻伤害-50%** | **"蓄力者"**：技能伤害x4，且释放时无敌 |

**肉鸽感**：你拿到了一堆"垃圾"遗物，但突然发现它们组合成了神级构筑——这种"垃圾变宝藏"的体验是肉鸽的核心乐趣。

### 维度6：Run专属机制（Run-Unique Mechanics）

**核心**：每局随机赋予玩家一个**全局规则改变**。

#### Run专属机制池（每局随机1个）

| 机制 | 效果 | 构筑影响 |
|------|------|----------|
| **元素潮汐** | 每5层切换全局元素（火/冰/雷），对应元素伤害+50%，其他-30% | 必须适应元素变化 |
| **生命交易** | 所有金币购买改为生命购买（花生命买东西） | 续航构筑优先 |
| **技能饥渴** | 技能无CD，但每次释放-5%生命 | 血换输出 |
| **共生契约** | 4人共享生命池（总和不变） | 必须保护脆皮 |
| **武器大师** | 所有角色可使用任意武器，无视职业限制 | 混搭构筑 |
| **诅咒狂欢** | 诅咒遗物效果翻倍，负面也翻倍 | 高风险构筑 |
| **时间裂缝** | 每10秒全场时停2秒（敌我不分） | 利用时停输出 |
| **镜像世界** | 所有敌人是玩家镜像 | 反制构筑 |
| **贫穷之神** | 无法获得金币，但击杀直接掉落装备 | 战斗收益流 |
| **进化压力** | 每过1层，随机1个角色获得1个改造（也可能负面） | 随机变异流 |

**肉鸽感**：这局是"元素潮汐"，上局是"生命交易"，两局的玩法完全不同。

## 总结：构筑肉鸽感检验表

| 检验项 | 改造前 | 改造后 |
|--------|--------|--------|
| 每局技能是否不同？ | 固定16个 | 基础+随机改造，数百种组合 |
| 遗物是否改变玩法？ | 数值+8% | 改变规则（双持、血法、玻璃炮） |
| 职业是否可变？ | 4固定 | 4×3变异=12种 |
| 早期选择是否影响后期？ | 否，随时换 | 是，路径承诺锁定选项池 |
| 负面道具是否有用？ | 纯负面 | 负面组合=神级构筑 |
| 每局是否有全局规则？ | 无 | 随机1个Run专属机制 |
| 构筑区分度 | "攻击流"vs"防御流" | "血法双持狂战"vs"延时分裂冰法"vs"玻璃炮狙击弓" |

4. **职业变异**（1周）—— 丰富选择
5. **路径承诺**（2周）—— 深度绑定
6. **负面构筑**（1周）—— 惊喜感
